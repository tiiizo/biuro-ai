# reports/

Agents save work results that you want to keep here, as Markdown files, for example `reports/review-2026-01-05.md` or `reports/pricing-options-2026-01-05.md`.

In this template everything in `reports/` except this README is git-ignored, because reports usually contain your own business data. If you want to version reports, remove the `reports/*` lines from `.gitignore` (and think twice if the repository is public).
