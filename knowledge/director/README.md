# knowledge/director

Curated input material for the `director` agent: notes, briefs, checklists, reference documents.

- The agent reads this folder when it is relevant to the task. It does not write here; it writes to its own memory and to `reports/`.
- Keep files short and focused. One topic per file works best.
- This folder is versioned. Do not put secrets, credentials or personal data here, especially if your repository is public.
