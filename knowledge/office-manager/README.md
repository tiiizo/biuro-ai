# knowledge/office-manager

Curated input for the `office-manager` agent, which writes `office.md` for the office dashboard (`dashboard/`).

- The agent reads this folder before every update. It does not write here; it writes `office.md` and its own memory.
- Useful content: which GitHub accounts or organisations to scan, repositories to skip, how to group projects into floors, projects that must never be shown together (separate floors, no shared colors or wording).
- This folder is versioned. Do not put secrets, credentials or personal data here, especially if your repository is public.
